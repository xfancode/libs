Мои библиотеки для ваших проектов.

## Доступные библиотеки

| Библиотека | Описание | Ссылка для подключения |
|------------|----------|------------------------|

## Как использовать

Просто скопируйте ссылку из таблицы и вставьте в ваш HTML:

```html

```
